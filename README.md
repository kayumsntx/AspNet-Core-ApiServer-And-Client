# ASP.NET Core API Server and Client

A practice project demonstrating how to build and consume an ASP.NET Core Web API using a separate client application.

## Project Overview

This project demonstrates the basic integration between an **ASP.NET Core Web API Server** and an **ASP.NET Core Client**.

The Server exposes API endpoints, while the Client communicates with the API using HTTP requests and processes the returned data.

## Features

* ASP.NET Core Web API
* API Controllers
* HTTP Client communication
* Client-Server Architecture
* REST API concepts
* JSON data exchange
* API request and response handling
* ASP.NET Core Client integration

## How It Works
The Client sends an HTTP request to the Web API Server.
The Server processes the request and returns data, usually in JSON format.
